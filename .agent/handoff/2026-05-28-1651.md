## 試したこと・結果

### 講師謝礼一括取込テスト（Pattern B）
- `I.attachFile('input[name="import_file"]', filePath)` で相対パスを直接渡す → 成功
- `path.resolve(process.cwd(), filePath)` で絶対パスに変換してから渡す → 失敗（CodeceptJS がプロジェクトルートを二重に付加してパスが壊れる）
- `verifyImportResult()` で `grabTextFrom('#top_err_info_msg_div')` によるエラー確認 → 成功（このページはエラー時も遷移しないため）
- 現状、サンプルCSVのフォーマット不正エラーが出る（`ファイルのフォーマットが不正です。（ID番号：計上日）`）→ `koushi_sharei_import_sample.csv` に実際のデータが入っていないため。ユーザーが実データを投入すれば正常系テストが通る。

### 講師謝礼手動入力登録テスト（Pattern A）
- 教師選択ポップアップ（別タブ）操作: `I.switchToNextTab()` でポップアップに入り、選択後 `I.wait(TIMEOUTS.TAB_SWITCH)` → `I.switchToNextTab()` で元タブへ戻る → 成功
  - ポップアップタブ自動クローズ後も `I.switchToNextTab()` が呼べる理由: `pages.indexOf(this.page)` が -1 を返すため CodeceptJS が `pages[0]`（元タブ）にフォールバックする
- 保存後エラー確認で `grabTextFrom('#top_err_info_msg_div')` を使用 → 失敗（成功時はページ遷移するため ElementNotFound）
- try-catch で囲む → 失敗（CodeceptJS Recorder が "Uncaught" エラーとして処理し async try-catch をバイパスする）
- `I.executeScript(() => { const el = document.querySelector('#top_err_info_msg_div'); return el ? el.textContent.trim() : ''; })` に変更 → 成功
- 日付バリデーション: `keijoubi`（計上日）は `from_datetime`（対象月）の翌月でなければならない業務ルールあり → CSV の from_datetime を 2026-04 に修正して解決
