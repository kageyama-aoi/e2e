## 試したこと・結果

### 成功
- `Promise.all([page.waitForLoadState('networkidle', {timeout:60000}), locator.click({timeout:60000})])` パターンで月謝作成ボタンのタイムアウト問題を解消（21秒でPASS）
- `runStudentPaymentSetup` 完了後に `I.grabCurrentUrl()` で record UUID を取得 → `output/tsukihi_ikatsu_session.json` に追記
- `verifyMonthlyFees` でJSONから UUID を読み込み `DetailView?record=UUID` で直接遷移（姓検索の同名混在問題を解消）
- setupテスト の `BeforeSuite` でJSONリセット → 月謝テスト単独実行時はJSONが残るのでそのまま動く

### 失敗
- `page.once('dialog', ...)` を追加 → CodeceptJS の既存ダイアログハンドラと競合して "Cannot accept dialog which is already handled!" エラー
- 姓（`月謝テスト{MMDD}`）のみで受講生を検索 → 複数回テスト実行で同名受講生が複数できる問題
