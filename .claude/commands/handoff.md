以下の手順でハンドオフを作成してください：

1. `.agent/handoff/HANDOFF.md` が存在する場合：
   - そのファイルの更新日時（ローカル時刻）を取得
   - `.agent/handoff/YYYY-MM-DD-HHMM.md` にリネーム

2. **先に Issue を更新する**（作業状況の正は Issue。AGENTS.md「作業状況の置き場所」）：
   - 保留・ユーザー待ちになったものは、状態ラベル（`blocked` / `waiting-user`）を付け、理由と再開条件を Issue にコメントする
   - 受け皿の Issue が無い残作業は Issue を作る
   - HANDOFF には残作業の一覧や保留理由を書かず、Issue 番号を書く

3. 新しい `.agent/handoff/HANDOFF.md` を以下のテンプレートに従って作成し、完了後「HANDOFF.mdを作成しました」と報告してください。各項目には、現在までのチャット履歴や作業内容からAI自身が自己の行動を要約し、具体的な内容を記入してから保存してください。単なる空のテンプレートのまま保存してはいけません。

---
# HANDOFF - {日時}

## 使用ツール
Claude Code / Codex CLI / Gemini CLI など、該当するツール名を記載

## 現在のタスクと進捗
- #番号 タスク名：このセッションでどこまで進んだか（詳細と残りは Issue 側）

## 試したこと・結果
- 成功したアプローチ
- 失敗したアプローチ（理由）

## 次のセッションで最初にやること
1. #番号 最初のアクション
2. #番号 次のアクション

## 注意点（このセッション限りのもの）
- 作業中ブランチ・未コミットの変更とその理由など
- 保留・ブロッカーは Issue に書いて番号だけ載せる（例: #218 blocked）
