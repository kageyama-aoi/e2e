新しいファイル・概念の配置を決定するゲートプロセスを実行してください。

## ステップ1：AGENTS.md の配置ルールを読み込む

`AGENTS.md` の「ディレクトリ配置ルール」と「run/ と scripts/ の配置ルール」（「誰が呼ぶか → どこに置くか」の表・ファイル名の決まり）を読み込み、現在の配置ルール（置いてよいもの／置いてはいけないもの）を把握する。

## ステップ2：対象ファイル・概念の性質を分類する

ユーザーが作ろうとしているファイルについて、以下の質問に答える形で性質を明確化する：

1. **このファイルは何をするものか？** （1〜2行で）
2. **手で書くものか、実行するたびに作られるもの（生成物）か？**
   - 生成物（結果・ログ・スクリーンショット・取得した HTML・抜き出し結果・一時ファイル）は git に入れず `output/` の下に書く。種類で置き場を分ける:
     - テスト間の受け渡し → `output/session/`
     - 調査・抜き出しの記録 → `output/probe/<名前>/`（使い捨ての調査スクリプトもここ）
     - テストが作る一時ファイル・ダウンロード → `output/work/`
     - 取得した画面 HTML → `output/html/<製品>/`
   - 手で書くものは次の質問へ。`output/` には置かない（掃除で消える・git に入らない）
3. **誰がいつ呼ぶか？**（見た目の種類ではなく呼び出し元で決める）
   - テスト実行中に CodeceptJS が `require()` する → `codecept/support/` または `codecept/pages/`
   - テストシナリオそのもの → `codecept/tests/`
   - テストへの入力データ（CSV・パラメータ） → `codecept/data/`
   - ランチャー・npm scripts がテストの実行に付けて呼ぶ（結果の表示・掃除・実行前チェック） → `run/` のサブフォルダ（`run/allure/` `run/cleanup/` `run/checks/`）
   - Claude Code のフックが呼ぶ → `.claude/hooks/`
   - pre-commit・CI・人やスキルが開発・保守のときに動かす → `scripts/` の用途別フォルダ（`docs/` `html/` `setup/` `testdata/` `debug/`）
   - 参考資料として残す取得データ（画面 HTML の写し）→ `scripts/html/snapshots/<製品>/`、人が手で貼る入力 → `scripts/html/inputs/`
4. **アプリの構造・画面に関する知識を持つか？**
   - Yes（メニュー定義、URL解決、Page Object） → `codecept/pages/`
   - No → 上記の分類を継続

## ステップ3：配置先を判定する

分類結果と AGENTS.md のルールを照合し、以下のいずれかを宣言する：

### パターンA：既存カテゴリに合致
```
【配置判定】
- 性質：{分類結果}
- 配置先：{ディレクトリ}/
- 理由：{AGENTS.mdのルールのどの記述に基づくか}
→ このまま実装に進んでよい
```

### パターンB：既存カテゴリに当てはまらない（新概念）
```
【配置判定】⚠️ 新概念 — 実装前にルール確立が必要
- 性質：{分類結果}
- 最も近いカテゴリ：{ディレクトリ}（ただし完全には合致しない）
- 理由：{何が既存ルールと合わない点か}
→ AGENTS.md の配置ルール表に新しい行を追記してから実装する
```

パターンBの場合は、AGENTS.md への追記案をユーザーに提示し、承認を得てから追記・実装を進める。

## ステップ4：完了報告

配置先が確定したら以下を報告する：
- 確定した配置先
- ファイル名の命名規則（AGENTS.md の命名規則セクションに基づく）。`scripts/` の道具は `<動詞>_<製品>_<対象>`（動詞は fetch / extract / gen / check / cleanup / debug / install）。製品名は、名前や置き場から推測せず中身（URL の形など）で確かめる
- 一緒に更新するもの: `scripts/` に道具を足すなら `scripts/README.md`（`scripts/html/` なら `scripts/html/README.md` も）の一覧に 1 行
- 次のアクション（実装開始 or AGENTS.md 更新）
